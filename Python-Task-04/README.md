---

## Program Descriptions

### 1. Calculator Functions

Uses separate functions for:

- Addition
- Subtraction
- Multiplication
- Division

Menu-driven program allowing users to select operations.

### 2. Student Information Manager

Accepts:

- Student Name
- Roll Number
- Branch
- Semester

Displays student information using functions.

### 3. Marks Analysis System

Accepts marks for 5 subjects.

Calculates:

- Total Marks
- Percentage
- Grade

Grade Criteria:

| Percentage | Grade |
|------------|-------|
| 90+ | A |
| 80+ | B |
| 70+ | C |
| 60+ | D |
| Below 60 | F |

### 4. File Handling Challenge

Stores student information in:

student_data.txt

Then reads and displays the saved records.

### 5. Password Vault Simulator

Stores:

- Website Name
- Username
- Password

inside:

vault.txt

Displays all saved records.
