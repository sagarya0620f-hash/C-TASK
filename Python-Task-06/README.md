# Student Cyber Security Management System

## Objective

The objective of this project is to develop a simple Student Cyber Security Management System using Python and C Programming. The project demonstrates programming concepts such as variables, loops, functions, arrays/lists, file handling, searching, and basic cybersecurity practices.

## Features

* Add Student
* View Students
* Search Student
* Delete Student
* Security Assessment
* Generate Report
* File Storage using students.txt

## Technologies Used

* Python 3
* C Programming
* Visual Studio Code

## Program Flow

1. Display Main Menu
2. Select an option
3. Perform the selected operation
4. Return to the Main Menu
5. Exit the program

## Challenges Faced

* Implementing file handling.
* Managing student records.
* Generating security reports.
* Handling user input correctly.

## Learning Outcomes

* Learned file handling.
* Improved problem-solving skills.
* Understood menu-driven programming.
* Gained knowledge of basic cybersecurity concepts.
