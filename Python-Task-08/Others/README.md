# Smart File Organizer

## Objective

The Smart File Organizer is a Python-based automation project that organizes files into different folders based on their file extensions. It helps keep directories clean and improves file management.

---

## Features

- Select any folder
- Validate folder path
- Scan all files
- Display total files and file extensions
- Automatically organize files into categories
- Generate file statistics
- Search files by name
- Search files by extension
- Detect duplicate file names
- Generate a report (file_report.txt)
- Exception handling for common errors

## How to Run

1. Open the project folder.
2. Run:

```bash
python smart_file_organizer.py
```

3. Enter the folder path when prompted.
4. The application will organize files and generate a report.
