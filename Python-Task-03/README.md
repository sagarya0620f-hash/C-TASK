# Programming Task 03

## Overview

This task focuses on loops, patterns, problem-solving, and basic automation concepts using Python and C Programming.

## Programs Included

### Python Programs

- multiplication_table.py
- number_analysis.py
- patterns.py
- password_attempt.py
- username_generator.py

### C Programs

- multiplication_table.c
- number_analysis.c
- patterns.c
- password_attempt.c
- username_generator.c

## Features

### Multiplication Table Generator
Generates the multiplication table of a given number up to 10.

### Number Analysis Tool
Calculates:
- Sum from 1 to N
- Count of Even Numbers
- Count of Odd Numbers

### Pattern Printing Challenge
Prints:
- Increasing Star Pattern
- Decreasing Star Pattern
- Number Triangle Pattern

### Password Attempt Simulator
- Maximum 3 attempts
- Displays Access Granted or Account Locked

### Username Generator
Generates multiple username suggestions using:
- First Name
- Last Name
- Birth Year

## Concepts Used

- for Loops
- while Loops
- Nested Loops
- Conditional Statements
- String Manipulation
- Basic Authentication Logic
