# Employee Management System

## Project Overview

The Employee Management System is a menu-driven Python application developed using Object-Oriented Programming (OOP). It allows users to manage employee records efficiently through a simple command-line interface.

## Features

- Add Employee
- View Employee Records
- Search Employee by ID
- Search Employee by Name
- Update Employee Details
- Delete Employee
- Salary Statistics
- Export Employee Data to CSV
- Read Employee Data from CSV
- Department-wise Employee Count
- Sort Employees by Salary

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- CSV File Handling

1. Open the project folder.
2. Run the program using:

```bash

```

3. Select the required option from the menu.
